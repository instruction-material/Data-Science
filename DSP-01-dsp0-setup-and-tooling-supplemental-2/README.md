# Repeat the Setup Calculations

Run the starter in the course IDE to reproduce 6 records, 32 trips and a
mean of 5.33. Save a separate project copy. In the copy, change the default
input in `main.py` from `sample.csv` to `practice.csv`. The practice file
contains 1, 1, 4 and 10. Its expected output is 4 records, 16 trips and a
mean of 4.00. An exported project can also run with
`python main.py --csv data/practice.csv`.

Reopen and rerun the original project. Record both inputs and verify that
saving the copy preserved the original result.
