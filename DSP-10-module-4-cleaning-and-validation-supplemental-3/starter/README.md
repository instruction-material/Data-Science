# Compare two label policies (starter)

Complete `compare_policies`. Run and summarize both policies on the same input. Report the differences in accepted records and trips.

Run main.py in the course IDE with the bundled input. For native Python 3.14, install pandas with `python -m pip install pandas==3.1.1` and run `python main.py`. Use `--input PATH` to try a separate CSV. A notebook can call `main(["--input", "PATH"])` from the project folder. Keep the original CSV unchanged.

Label repair accepts 5 of 10 records with 24 trips. Exact labels only accepts 3 of 10 with 16 trips. Report the differences of 2 records and 8 trips.
