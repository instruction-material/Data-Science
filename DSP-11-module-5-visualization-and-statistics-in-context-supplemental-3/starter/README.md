# Compare pooled and within-session correlation (starter)

Complete split_sessions in main.py. Run main.py in the site IDE or use python main.py with native Python. Use --input PATH in a terminal to compare a copied CSV. Keep the original input. The project uses the standard library.

Six paired rows show positive pooled correlation. Each three-record session has r = -1. Use separate denominators. A constant or single-point set has undefined r, reported as null.
